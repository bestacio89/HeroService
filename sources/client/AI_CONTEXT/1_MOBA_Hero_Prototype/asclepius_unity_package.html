Silhouette & Morphology

Tall, broad-shouldered divine healer — the calm authority of a physician who has conquered death itself. ~1.95m, substantial build without being a brawler: wide chest, strong arms used to lifting fallen warriors, serene bearing. Long dark curling hair, full dark beard, deep amber-gold eyes that glow faintly with divine life energy. Moves with deliberate, unhurried gravitas — he does not rush because he cannot be stopped. A god who walks into the worst wound on the battlefield and does not flinch.

Divine Armor — Sacred Physician Paladin

A fusion of Greek divine armor and the healer's craft: heavy bronze-green patinated breastplate over a white physician's chiton robe, the hem visible below the armor. Thick greaves, broad pauldrons with serpent-head detailing at each shoulder. A sacred laurel wreath of glowing jade light crowns the head rather than a helmet. The breastplate has the Rod of Asclepius embossed at the center — a serpent coiled around a rod, glowing with warm green-gold healing light. Heavy sandaled boots, leather bracers. A physician's satchel at the hip — not decorative but actively used in ability animations.

Sacred Weapon — Rod of Asclepius

The Rod of Asclepius — not a combat weapon but a divine implement of medicine. A plain dark wood rod slightly taller than Asclepius himself, with a single serpent coiled around its length. The serpent is alive — it shifts, watches, and glows with warm jade light at the scales' edges. During offensive abilities the rod is used as a melee bludgeon; during healing the serpent uncoils from the rod and reaches toward the target before retracting. During the Ultimate the serpent fully detaches and grows enormous, flying across the battlefield as a divine healer and destroyer simultaneously.

Sacred Companion — The Serpent of Life

The living serpent on the Rod of Asclepius is always present — coiled at rest on the rod during movement, head raised and eyes glowing during healing casts, fully extended outward during Skill 2 at maximum range. It is both a visual identifier and a gameplay VFX anchor: healing beams originate from the serpent's mouth, not from Asclepius's hands. During the Ultimate it detaches entirely and becomes an autonomous flying serpent the size of a horse that orbits the battlefield, healing allies and poisoning enemies simultaneously.

System Proposal

Asclepius is a Paladin Support Tank — the highest HP pool in the roster, excellent physical and magic defense, and a unique Heal Power stat that scales his healing independently of physical attack. He uses a Vitality resource (fixed at 100) that regenerates continuously — representing his divine life force.

He excels at holding the front line while continuously sustaining his team. His damage is secondary; his value is presence, healing output, and the Ultimate — a battlefield-defining serpent that can resurrect a fallen ally at maximum rank, the most powerful ability in the roster and the reason teams keep Asclepius alive at all costs.

Heal Power is a dedicated stat in RuntimeHeroStats that scales healing independently — like magic power for healers. It grows from 210 → 520 over 15 levels. Vitality is a float capped at 100, regenerating per second and spent on abilities. The Ultimate at Rank III can revive a dead ally — handled as a revival coroutine that reconstructs the ally's HP to 40% and re-enables their controller.

// HeroDefinition.cs
// ScriptableObject — MOBA 15-level hero data.
// Extended for Asclepius: dedicated Heal Power stat, Vitality resource,
// passive crisis thresholds, aura sustain cost, revive window + HP percent.

using UnityEngine;
using System;

[CreateAssetMenu(menuName = "Game/Hero Definition", fileName = "HeroDefinition")]
public class HeroDefinition : ScriptableObject
{
    [Header("Identity")]
    public string   heroId      = "asclepius";
    public string   displayName = "Asclepius";
    public HeroRole role        = HeroRole.Support;

    [Header("Core progression — Level 1 to 15")]
    public ScaledStat maxHp          = new(4200f, 8600f);
    public ScaledStat hpRegen         = new(16.0f, 34.0f);
    public ScaledStat vitalityRegen   = new(14.0f, 28.0f);
    public ScaledStat healPower       = new(210f,  520f);
    public ScaledStat physicalAttack  = new(140f,  270f);
    public ScaledStat physicalDefense = new(62f,   145f);
    public ScaledStat magicDefense    = new(40f,   98f);
    public ScaledStat attackSpeed     = new(0.78f, 1.00f);

    [Header("Fixed properties")]
    public float moveSpeed         = 230f;
    public float basicAttackRange  = 3.0f;
    public float basicAttackAngle  = 90f;
    public float attackSpeedRatio  = 1.0f;
    public float maxVitality       = 100f;
    public float serpentReachRange = 7.0f;
    public float vitOnBasicHit     = 8f;
    public float weakenDuration    = 2.0f;
    public float weakenAmount      = 0.10f; // 10% ATQ reduction

    [Header("Passive — Unbreakable Constitution")]
    public float passiveDamageReduction = 0.08f; // 8% always

    public float crisisSurgeHealPerSec  = 0.12f; // 12% max HP / sec
    public float crisisSurgeDuration    = 4.0f;
    public float crisisSurgeCooldown    = 40.0f;
    public float vigilHpThreshold       = 0.50f; // below 50% HP
    public float vigilHealBoost         = 0.15f; // +15% to ally heals

    [Header("Ability ranks")]
    public AbilityRankData basicAttack = new("Divine Smite",
        new[] { 0f }, new[] { 0f }, new[] { 0f }, 1.10f);

    public AbilityRankData skillOne = new("Pharmakeia Aura",
        new[] { 55f,  75f,  95f,  115f },  // base heal / sec
        new[] { 8f,   8f,   8f,   8f   },  // vit / sec sustained cost
        new[] { 10f,  9f,   8f,   7f   }, 0.33f);

    public AbilityRankData skillTwo = new("Serpent's Reach",
        new[] { 320f, 420f, 520f, 620f },
        new[] { 28f,  28f,  28f,  28f  },
        new[] { 8f,   7f,   6f,   5f   }, 0.72f);

    public AbilityRankData ultimate = new("Divine Resurrection",
        new[] { 280f, 380f, 500f },  // heal per ally pass
        new[] { 80f,  88f,  100f },
        new[] { 110f, 95f,  80f  }, 0f); // scaling applied via healPower in controller

    [Header("Ultimate — Great Serpent")]
    public float[] serpentDurations    = { 8f, 10f, 12f };
    public float[] venomDmgPerTick     = { 60f, 80f, 105f };
    public float   reviveHpPercent     = 0.40f; // 40% max HP on revive
    public float   reviveWindowSeconds = 6f;   // death must be within 6s

    public RuntimeHeroStats CreateRuntime(int level)
    {
        level = Mathf.Clamp(level, 1, 15);
        return new RuntimeHeroStats
        {
            level           = level,
            maxHp           = maxHp.Evaluate(level),
            hpRegen         = hpRegen.Evaluate(level),
            vitalityRegen   = vitalityRegen.Evaluate(level),
            healPower       = healPower.Evaluate(level),
            physicalAttack  = physicalAttack.Evaluate(level),
            physicalDefense = physicalDefense.Evaluate(level),
            magicDefense    = magicDefense.Evaluate(level),
            attackSpeed     = attackSpeed.Evaluate(level),
            moveSpeed       = moveSpeed,
            basicAttackRange = basicAttackRange,
            basicAttackAngle = basicAttackAngle,
            attackSpeedRatio = attackSpeedRatio,
            maxVitality      = maxVitality
        };
    }

public enum HeroRole { Tank, Fighter, Assassin, Mage, Marksman, Support, MageAssassin }

[Serializable]
public struct ScaledStat
{
    public float level1, level15;
    public ScaledStat(float l1, float l15) { level1 = l1; level15 = l15; }
    public float Evaluate(int level)
    {
        level = Mathf.Clamp(level, 1, 15);
        return level == 1 ? level1 : Mathf.Lerp(level1, level15, (level - 1f) / 14f);
    }
}

[Serializable]
public class AbilityRankData
{
    public string  abilityName;
    public float[] baseDamage;   // doubles as base heal for support abilities
    public float[] vitalityCost;
    public float[] cooldown;
    public float   scalingHealPower;

    public AbilityRankData(string n, float[] dmg, float[] cost, float[] cd, float scale)
    { abilityName = n; baseDamage = dmg; vitalityCost = cost; cooldown = cd; scalingHealPower = scale; }

    public float HealAtRank   (int r, float hp) => baseDamage  [Mathf.Clamp(r-1,0,baseDamage.Length-1)]   + hp * scalingHealPower;
    public float VitCostAtRank(int r)          => vitalityCost[Mathf.Clamp(r-1,0,vitalityCost.Length-1)];
    public float CooldownAtRank(int r)         => cooldown    [Mathf.Clamp(r-1,0,cooldown.Length-1)];
}

[Serializable]
public struct RuntimeHeroStats
{
    public int   level;
    public float maxHp, hpRegen;
    public float maxVitality, vitalityRegen;
    public float healPower, physicalAttack, physicalDefense, magicDefense;
    public float attackSpeed, moveSpeed, basicAttackRange, basicAttackAngle, attackSpeedRatio;
}
C# AsclepiusController.cs
// AsclepiusController.cs
// Main controller: Vitality resource, Pharmakeia sustained aura (Vit/sec cost),
// Serpent's Reach single-target heal + cleanse + overflow shield,
// passive crisis surge + vigil heal boost, damage reduction,
// Great Serpent ultimate with ally heal passes, venom ticks, and Rank III revive.

using UnityEngine;
using UnityEngine.AI;
using System.Collections;
using System.Collections.Generic;

[RequireComponent(typeof(NavMeshAgent))]
public class AsclepiusController : MonoBehaviour
{
    [Header("Data")]
    [SerializeField] private HeroDefinition heroDefinition;
    [SerializeField, Range(1, 15)] private int heroLevel = 1;

    [Header("Ability Ranks")]
    [SerializeField, Range(1, 4)] private int skillOneRank = 1;
    [SerializeField, Range(1, 4)] private int skillTwoRank = 1;
    [SerializeField, Range(1, 3)] private int ultimateRank = 1;

    [Header("Scene References")]
    [SerializeField] private Animator           animator;
    [SerializeField] private NavMeshAgent       agent;
    [SerializeField] private AsclepiusCombatVFX combatVfx;
    [SerializeField] private Transform           rodTip;
    [SerializeField] private Transform           serpentHead;
    [SerializeField] private LayerMask           allyMask;
    [SerializeField] private LayerMask           enemyMask;

    [Header("Runtime")]
    [SerializeField] private RuntimeHeroStats stats;
    [SerializeField] private float currentHp;
    [SerializeField] private float currentVitality;
    [SerializeField] private bool  isDead;

    private float basicCooldown, skillOneCooldown, skillTwoCooldown, ultimateCooldown;
    private float crisisSurgeCooldown;
    private bool  crisisSurgeActive;
    private bool  auraActive;
    private bool  serpentUnleashed;
    private       Coroutine auraCoroutine;

    // Tracks recently deceased allies for revive (ally Health component → time of death)
    private readonly Dictionary<AllyHealth, float> recentDeaths = new();

    public float HpPercent       => stats.maxHp       > 0f ? currentHp       / stats.maxHp       : 0f;
    public float VitalityPercent => stats.maxVitality > 0f ? currentVitality / stats.maxVitality : 0f;
    public bool  AuraActive      => auraActive;
    public bool  IsDead          => isDead;

    // Vigil heal boost: +15% when Asclepius is below 50% HP
    private float VigilMultiplier => HpPercent < heroDefinition.vigilHpThreshold
                                      ? 1f + heroDefinition.vigilHealBoost : 1f;

    private void Reset() { agent = GetComponent<NavMeshAgent>(); animator = GetComponentInChildren<Animator>(); }
    private void Awake() { if (agent == null) agent = GetComponent<NavMeshAgent>(); ApplyLevel(heroLevel, true); }

    private void Update()
    {
        if (isDead || heroDefinition == null) return;
        TickCooldowns();
        RegenerateResources();
        CheckCrisisPassive();
        PruneExpiredDeaths();
        UpdateAnimator();
    }

    public void ApplyLevel(int newLevel, bool fullRestore = false)
    {
        heroLevel = Mathf.Clamp(newLevel, 1, 15);
        stats     = heroDefinition.CreateRuntime(heroLevel);
        agent.speed = stats.moveSpeed / 100f;
        if (fullRestore) { currentHp = stats.maxHp; currentVitality = stats.maxVitality; }
        else currentHp = Mathf.Min(currentHp, stats.maxHp);
    }

    public void MoveTo(Vector3 worldPoint)
    {
        if (isDead) return;
        agent.isStopped = false;
        agent.SetDestination(worldPoint);
    }

    // ── BASIC ATTACK — Divine Smite: AoE wedge + Weaken + Vit regen ───────
    public void BasicAttack()
    {
        if (isDead || basicCooldown > 0f) return;
        basicCooldown = 1f / Mathf.Max(0.1f, stats.attackSpeed * stats.attackSpeedRatio);
        float dmg = stats.physicalAttack * heroDefinition.basicAttack.scalingHealPower;
        animator.SetTrigger("BasicAttack");
        combatVfx.PlaySmite(rodTip.position);

        bool hitAnything = false;
        foreach (var col in Physics.OverlapSphere(transform.position, stats.basicAttackRange, enemyMask))
        {
            Vector3 toEnemy = (col.transform.position - transform.position).normalized;
            if (Vector3.Angle(transform.forward, toEnemy) > stats.basicAttackAngle * 0.5f) continue;
            col.GetComponent<Health>()?.ApplyPhysicalDamage(dmg);
            col.GetComponent<StatusEffectReceiver>()?.ApplyWeaken(heroDefinition.weakenAmount, heroDefinition.weakenDuration);
            hitAnything = true;
        }
        if (hitAnything) GainVitality(heroDefinition.vitOnBasicHit);
    }

    // ── SKILL 1 — Pharmakeia Aura: sustained heal field ───────────────────
    public void ToggleAura()
    {
        if (auraActive) { EndAura(); return; }
        if (isDead || skillOneCooldown > 0f || serpentUnleashed) return; // cannot run with Sk2 active check if needed
        auraCoroutine = StartCoroutine(AuraRoutine(skillOneRank));
    }

    private IEnumerator AuraRoutine(int rank)
    {
        auraActive = true;
        agent.isStopped = false; // Asclepius can still move while aura is active
        float maxDuration  = 6f + rank * 2f;
        float elapsed      = 0f;
        float tick         = 0f;
        float vitCostPerSec = heroDefinition.skillOne.VitCostAtRank(rank);
        float healPerSec   = heroDefinition.skillOne.HealAtRank(rank, stats.healPower);
        float auraRadius   = 7.0f;
        float defBuff      = 0.10f + rank * 0.02f;

        animator.SetBool("AuraActive", true);
        combatVfx.StartAura(transform.position, auraRadius);

        while (auraActive && elapsed < maxDuration)
        {
            // Check Vit drain
            if (currentVitality < vitCostPerSec * Time.deltaTime) { EndAura(); yield break; }
            SpendVitality(vitCostPerSec * Time.deltaTime);

            tick    += Time.deltaTime;
            elapsed += Time.deltaTime;

            // Heal tick every 0.5s, buff application continuous
            if (tick >= 0.5f)
            {
                tick = 0f;
                float tickHeal = healPerSec * 0.5f * VigilMultiplier;
                foreach (var col in Physics.OverlapSphere(transform.position, auraRadius, allyMask))
                {
                    var ally = col.GetComponent<AllyHealth>();
                    if (ally != null) ally.Heal(tickHeal);
                    col.GetComponent<DefenseBuffReceiver>()?.ApplyDefBuff(defBuff, 0.6f); // refresh every tick
                }
                combatVfx.PulseAura(transform.position, auraRadius);
            }
            yield return null;
        }
        EndAura();
    }

    private void EndAura()
    {
        if (!auraActive) return;
        auraActive = false;
        if (auraCoroutine != null) StopCoroutine(auraCoroutine);
        skillOneCooldown = heroDefinition.skillOne.CooldownAtRank(skillOneRank);
        animator.SetBool("AuraActive", false);
        combatVfx.StopAura();
    }

    // ── SKILL 2 — Serpent's Reach: targeted heal + cleanse + shield ────────
    public bool TryCastSkillTwo(AllyHealth target)
    {
        if (isDead || skillTwoCooldown > 0f || target == null) return false;
        if (currentVitality < heroDefinition.skillTwo.VitCostAtRank(skillTwoRank)) return false;
        if (Vector3.Distance(transform.position, target.transform.position) > heroDefinition.serpentReachRange) return false;

        SpendVitality(heroDefinition.skillTwo.VitCostAtRank(skillTwoRank));
        skillTwoCooldown = heroDefinition.skillTwo.CooldownAtRank(skillTwoRank);
        animator.SetTrigger("SerpentReach");
        StartCoroutine(SerpentReachRoutine(target, skillTwoRank));
        return true;
    }

    private IEnumerator SerpentReachRoutine(AllyHealth target, int rank)
    {

    private IEnumerator GreatSerpentRoutine(int rank)

HLSL PharmakeiaAuraRing.shader
// PharmakeiaAuraRing.shader
// Ground ring for the Pharmakeia Aura — a gentle healing circle.
// Unlike damage zones it uses soft concentric rings with a warm jade fill,
// breathing slowly to signal sustained healing rather than danger.
// Follows Asclepius as he moves — applied to a disc quad parented to his feet.

Shader "Asclepius/PharmakeiaAuraRing"
{
    Properties
    {
        _FillColor    ("Fill Color",  Color)         = (0.15, 0.75, 0.40, 0.22)
        _RingColor    ("Ring Color",  Color)         = (0.30, 0.95, 0.60, 0.80)
        _RuneColor    ("Rune Color",  Color)         = (0.60, 1.00, 0.78, 0.90)
        _Radius       ("Radius",      Float)         = 7.0
        _RingWidth    ("Ring Width",  Range(0.05,1)) = 0.30
        _BreathSpeed  ("Breath Speed", Range(0,4))   = 1.2
        _RuneSpeed    ("Rune Rotation", Range(-3,3)) = 0.8
        _AuraStrength ("Aura Strength", Range(0,1))  = 1.0
    }

    SubShader
    {
        Tags { "RenderType"="Transparent" "Queue"="Transparent" "RenderPipeline"="UniversalPipeline" }
        Blend SrcAlpha OneMinusSrcAlpha
        ZWrite Off
        Cull Off

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            CBUFFER_START(UnityPerMaterial)
                float4 _FillColor;
                float4 _RingColor;
                float4 _RuneColor;
                float  _Radius;
                float  _RingWidth;
                float  _BreathSpeed;
                float  _RuneSpeed;
                float  _AuraStrength;
            CBUFFER_END

            struct Attributes { float4 positionOS : POSITION; float2 uv : TEXCOORD0; };
            struct Varyings   { float4 positionCS : SV_POSITION; float2 uv : TEXCOORD0; };

            float2 RotUV(float2 uv, float a)
            {
                float s = sin(a); float c = cos(a); uv -= 0.5;
                return float2(uv.x*c - uv.y*s, uv.x*s + uv.y*c) + 0.5;
            }

            Varyings vert(Attributes IN)
            {
                Varyings OUT;
                OUT.positionCS = GetVertexPositionInputs(IN.positionOS.xyz).positionCS;
                OUT.uv = IN.uv;
                return OUT;
            }

            half4 frag(Varyings IN) : SV_Target
            {
                float2 centered = IN.uv * 2.0 - 1.0;
                float dist = length(centered); // 0=center, 1=edge at radius

                // Breathing fill — gentle sine pulse
                float breath = 0.80 + 0.20 * sin(_Time.y * _BreathSpeed * 6.2831);

                // Soft fill inside ring
                float fill = smoothstep(1.0, 0.85, dist) * breath;

                // Outer ring edge
                float ring = smoothstep(1.0, 1.0 - _RingWidth * 0.8, dist)
                           * (1.0 - smoothstep(1.0 - _RingWidth * 0.8, 1.0 - _RingWidth * 1.4, dist));

                // Rotating rune pattern (simplified — concentric dotted ring)
                float2 rotUv  = RotUV(IN.uv, _Time.y * _RuneSpeed);
                float runeAngle = atan2(rotUv.y - 0.5, rotUv.x - 0.5);
                float rune = pow(0.5 + 0.5 * sin(runeAngle * 12.0), 8.0) * smoothstep(0.90, 0.85, dist) * smoothstep(0.70, 0.80, dist);

                half3 color = _FillColor.rgb   * fill
                            + _RingColor.rgb   * ring
                            + _RuneColor.rgb   * rune;
                float alpha = (_FillColor.a * fill * 0.6 + _RingColor.a * ring + _RuneColor.a * rune * 0.8) * _AuraStrength;

                return half4(color, saturate(alpha));
            }
            ENDHLSL
        }
    }
}
HLSL RevivalPillarBeam.shader
// RevivalPillarBeam.shader
// The column of divine light that erupts when the Great Serpent resurrects a fallen ally.
// Applied to a tall vertical cylinder mesh at the revival target's position.
// Brilliant white-gold center, jade green fringe. Scrolls upward rapidly.
// _ReviveProgress: 0 = beginning (small, faint), 1 = peak brilliance, fades back to 0.

Shader "Asclepius/RevivalPillarBeam"
{
    Properties
    {
        _CoreColor    ("Core Color",   Color)           = (1.00, 1.00, 0.96, 1.0)
        _JadeColor    ("Jade Color",   Color)           = (0.30, 0.95, 0.60, 0.90)
        _GoldColor    ("Gold Fringe",  Color)           = (0.95, 0.80, 0.20, 0.80)
        _Intensity    ("Intensity",    Range(0,20))     = 10.0
        _ReviveProgress("Revive Progress", Range(0,1)) = 0.0
        _ScrollSpeed  ("Scroll Speed", Range(0,16))    = 7.0
        _FresnelPow   ("Fresnel Power", Range(1,6))    = 1.8
        _Dissolve     ("Dissolve (fade out)", Range(0,1)) = 0.0
    }

    SubShader
    {
        Tags { "RenderType"="Transparent" "Queue"="Transparent+15" "RenderPipeline"="UniversalPipeline" }
        Blend SrcAlpha One
        ZWrite Off
        Cull Off

        Pass
        {
            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            CBUFFER_START(UnityPerMaterial)
                float4 _CoreColor;
                float4 _JadeColor;
                float4 _GoldColor;
                float  _Intensity;
                float  _ReviveProgress;
                float  _ScrollSpeed;
                float  _FresnelPow;
                float  _Dissolve;
            CBUFFER_END

            struct Attributes { float4 positionOS : POSITION; float3 normalOS : NORMAL; float2 uv : TEXCOORD0; };
            struct Varyings   { float4 positionCS : SV_POSITION; float2 uv : TEXCOORD0; float3 normalWS : TEXCOORD1; float3 viewDirWS : TEXCOORD2; };

            Varyings vert(Attributes IN)
            {
                Varyings OUT;
                VertexPositionInputs pos = GetVertexPositionInputs(IN.positionOS.xyz);
                VertexNormalInputs   nor = GetVertexNormalInputs(IN.normalOS);
                OUT.positionCS = pos.positionCS;
                OUT.uv         = IN.uv;
                OUT.normalWS   = normalize(nor.normalWS);
                OUT.viewDirWS  = GetWorldSpaceNormalizeViewDir(pos.positionWS);
                return OUT;
            }

            half4 frag(Varyings IN) : SV_Target
            {
                // Upward scroll — energy racing toward the sky
                float2 uv = IN.uv;
                uv.y -= _Time.y * _ScrollSpeed * 0.05; // normalized scroll

                // Vertical energy bands scrolling upward
                float band = frac(uv.y * 6.0 - _Time.y * _ScrollSpeed * 0.12);
                float energy = smoothstep(0.0, 0.3, band) * (1.0 - smoothstep(0.3, 0.75, band));

                // Radial falloff from pillar center (uv.x = 0.5 = center)
                float radial = pow(1.0 - abs(IN.uv.x * 2.0 - 1.0), 2.5);

                // Fresnel for edge glow on cylinder
                float fresnel = pow(1.0 - saturate(dot(IN.normalWS, IN.viewDirWS)), _FresnelPow);

                // Color blend: white core, jade mid, gold at outer fringe
                half3 color;
                float fRatio = saturate((1.0 - radial - 0.3) * 3.3);
                if (fRatio < 0.5)
                    color = lerp(_CoreColor.rgb, _JadeColor.rgb, fRatio * 2.0);
                else
                    color = lerp(_JadeColor.rgb, _GoldColor.rgb, (fRatio - 0.5) * 2.0);

                float peakScale = _ReviveProgress * (1.0 - _Dissolve);
                float alpha     = (radial * 0.6 + energy * 0.3 + fresnel * 0.5) * peakScale * _CoreColor.a;

                return half4(color * _Intensity, saturate(alpha));
            }
            ENDHLSL
        }
    }
}
